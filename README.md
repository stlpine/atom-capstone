# A Real2Sim Pipeline for Humanoid Imitation Learning

**Team Atom** · Yonsei University Computer Capstone Design · May 2026

Project homepage for our capstone: collecting robot manipulation demonstrations inside a photorealistic 3D Gaussian Splatting reconstructed simulation using XR teleoperation, then training an imitation learning policy with ACT.
